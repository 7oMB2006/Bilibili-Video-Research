# Bilibili Video Research

把哔哩哔哩链接交给 Agent，并说明你想研究什么。BVR 根据问题使用字幕、
语音或视频画面，整理能够追溯到原视频的证据。

## 开始使用

本页对应 `0.2.0` 通用宿主协议候选，尚未发布。旧宿主和旧 BVR 专用桥不兼容。

### 安装前准备

- **DFSC `0.6.0`**：还须具备通用宿主 v1、通用独立配置和启动授权。
  已验收的 Windows 组合基于 main `dcab32806645502250ba1c8efd56e153e95d657b`，
  同版号旧构建或未验证平台不能仅凭版本号判断可用。
- **Node.js 24+ 与 BVR 本体**：同一环境准备 Node.js 并加入 PATH，
  另行更新带 `dfscHostApiVersion: 1` 的本体、安装依赖并登记路径。
  FFmpeg 和 yt-dlp 通常随本体的 npm 依赖提供，不要求重复安装。
- **模型访问与额度**：跟随模式需可用会话账户并明确确认；
  独立模式自备主力连接，ASR 按需单独配置，调用可能产生费用。
- **可选 Cookie**：只有匿名访问不足时才准备自己授权的本地文件。

市场中的版本与准备项是作者声明，不代表已检测本机、安装本体或取得账户授权。
这些字段由 `dfsc.plugin.json` 提供，不会从正文自动提取。

### 操作步骤

1. 显式更新外部 BVR 本体与依赖；安装插件资源不会自动安装本体或 Node.js。
2. 按[插件技术说明](../README.md)登记本体路径并检查环境，再打开配置齿轮。
3. 选择跟随 DFSC 会话，或分别设置主力模型与 ASR 的独立连接，然后保存。
4. 启用 MCP 服务，按提示手动重启需要使用它的空闲会话。
5. 在能力页确认实际连接，再提交视频链接与研究问题。

```text
/bvr 请整理这个视频介绍的项目、使用条件，并区分视频证据与推断。
https://www.bilibili.com/video/BV1dPeP6REwM/
```

## 选择证据

| 模式 | 读取内容 | 适合的问题 |
| --- | --- | --- |
| 语言 | 字幕，必要时使用 ASR | 讲述内容、项目推荐、主张 |
| 视觉 | 视频画面 | 界面、图表、演示步骤 |
| 多模态 | 语言与画面 | 核对讲解与屏幕证据 |

## 模型与费用

跟随模式使用实际调用会话已生效的账户、地区、渠道和适用模型，
首次模型请求需要会话内明确确认。不因失败从 Plan 自动回退到直调 API。
语音转写使用专用 ASR 能力，不等于聊天模型可以直接处理音频。

独立模式下，主力与 ASR 各有自己的地址、Key 和模型。
切换 DFSC 聊天账户不会修改这些独立连接。
Step ASR 三项须同时填写；全空时不借用主力 Key。旧 Key 与授权不会自动迁移。
模型调用可能消耗余额或套餐额度；本地环境检查不验证真实可用性或计费。
在途请求已经发生的费用不能撤销。

## 数据边界

媒体、字幕、公开元数据和按需采样的评论可能发送给所选提供商。
普通公开视频不强制要求 Cookie；需要时只使用自己明确授权的本地文件。
不要把 Key、Cookie、私密配置或单次启动上下文贴进对话或问题反馈。
这是本机原生插件集成，不是恶意插件沙箱。

完整安装命令、兼容性和独立提供商配置见
[插件技术说明](../README.md)。项目文档和教程可从本页的相关链接打开。
